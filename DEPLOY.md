# Deploy to GitHub Pages
Username: TODO   Repo name: TODO (example: genmath-g11-t2)
1. Unzip. Open the github-upload folder.
2. github.com > New repository > Public > Create.
3. Choose "uploading an existing file". Drag everything INSIDE github-upload (so index.html is at the top level). Commit.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Open https://TODO-username.github.io/TODO-repo/ after 1 to 2 minutes.
6. Android: Chrome menu > Install app. iPhone: Safari > Share > Add to Home Screen.
7. Airplane test: close the app, switch on airplane mode, open it from the Home screen.
Adding a week: upload content/wNN.js, content/weeks.js (set file), and sw.js (add the file to FILES and bump CACHE_VERSION).
